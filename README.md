📌 Project Overview

This project is a creative portfolio website designed to showcase personal branding, skills, and services in a visually engaging way. It combines HTML, Tailwind CSS, custom CSS animations, and JavaScript to deliver a modern, animated, and responsive single-page portfolio.

The site highlights:

A strong hero section with animated background effects

Core skills and services

Call-to-action contact section

Smooth scrolling and dynamic configuration support

🎯 Purpose of the Project

The purpose of this portfolio is to:

Present personal skills and services professionally

Demonstrate front-end web development and UI/UX skills

Combine creativity and technology through animations and interactions

Serve as a personal or academic portfolio project

🛠️ Technologies Used

HTML5 – Page structure and content

Tailwind CSS (CDN) – Responsive layout and utility-first styling

Custom CSS – Animations and visual effects (particles, glow, waves, pulse rings)

JavaScript – Dynamic content updates, smooth scrolling, and configuration handling

✨ Key Features

Fully responsive design (desktop, tablet, mobile)

Animated background with particles, grid lines, waves, and pulse rings

Neon-style cards with hover effects

Smooth scrolling navigation

Editable text and color configuration via JavaScript

Clean, modern, and creative UI design

📂 Project Structure
/portfolio-project
│── index.html   # Main HTML file (contains HTML, CSS, and JS)
│── README.md    # Project documentation
🚀 How to Run the Project

Download or copy the index.html file

Open the file using any modern web browser (Chrome, Edge, Firefox)

No server or installation required (runs locally)

✏️ Customization Guide

You can easily customize the portfolio by editing:

Name & Titles – Hero section text

Skills & Services – Skill badges and service cards

Colors – Primary and secondary colors in the JavaScript config

Email Address – Contact section email link

All editable values are located inside the JavaScript configuration object.
